# usage-meter

Claude Code のプラグインです。claude.ai のサブスクリプションの使用率（5時間枠と週枠）を、
入力欄の上の1行とステータスラインに、バーと色（60%未満は青、60%以上は黄、80%以上は赤）で表示します。
ターミナル、VS Code、デスクトップ、モバイル、ウェブ版で使えます。
API キーで使っている場合は、使用率が取れないので何も表示しません。最初の応答が返るまでも空です。

## インストール

    /plugin install usage-meter --marketplace osawapro13-design/usage-meter
